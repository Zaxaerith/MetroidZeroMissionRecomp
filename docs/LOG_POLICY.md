# Preview logging policy

No whole-route/per-instruction/per-memory-access traces, trajectory sweeps or
long frame bisection. A real bug diagnostic must state a specific hypothesis
and a finite event/frame/subsystem window. Consult decomp before tracing.
Routine acceptance keeps endpoints, hashes, coverage and exit status only.
Use --no-wav; keep the latest successful build and small current smoke reports.
Old strict/oracle/instrumentation tools are locally archived and inactive.

Checkpoint020 audited logical file sizes and deleted5405 obsolete log files.
Its inventory/keep-delete plan/results remain local. Checkpoint021 additionally
removes obsolete binary backups, duplicate WAVs and per-access oracle stdout,
and retires optional debug build outputs. Production generated/build/cache data
remain local and ignored; no copyrighted material enters public Git.

Progress uses Build/Boot/Title/New Game/Gameplay/Room transition/Combat/Audio/
Save-load/Smoke test and honest AOT/healed/interpreted/miss counters. No subjective
completion percentage and no zero-coverage release requirement.
