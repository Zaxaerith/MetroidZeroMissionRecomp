# Experimental Preview limits

- USA BMXErev0 only; Europe/Japan untested. Full campaign, bosses/endings and
  broad compatibility are untested. Representative room movement/fire/jump,
  enemy contact and save-station/restart/load have passed native smoke.
- Physical keyboard/controller devices and listening are user-deferred.
- Native routes use explicit interpreter fallback; healed execution was0.
  Strict-static completeness is not a preview requirement.
- Earlier independent mGBA samples diverged; full emulator fidelity is not
  certified. Long oracle/frame research is retired, not a release gate.
- Exact whole-decomp rebuild/global symbol import is unverified. MIT C/ASM
  reuse is allowed when actual function/version/ABI behavior is verified.
- Unknown mutable code images remain live fallback. Production full-image
  guards and IRQ-aware stack continuations must not be removed as debug code.
- Framework/generated compiler warnings remain; successful clean build and
  representative gameplay do not qualify every compiler/runtime path.
